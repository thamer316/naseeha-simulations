# محاكيات النصيحة التفاعلية

محاكيات تعليمية بسيطة (HTML/Canvas بلا اعتماديات) تُستضاف عبر GitHub Pages
وتُضمَّن داخل دروس موقع الدورات (naseehamath.com) عبر `iframe`.

## المحاكيات

| المحاكاة | المسار | الوصف |
| --- | --- | --- |
| قابلية الغازات للانضغاط | `gas-compression/` | وعاء بمكبس: الغاز ينضغط لأن بين جسيماته فراغات كبيرة، والمادة الصلبة المتراصّة لا تنضغط |
| الحركة العشوائية لجسيمات الغاز | `gas-random-motion/` | جسيمات داخل إناء دائري تتحرك حركة مستمرة وعشوائية وسريعة بخطوط مستقيمة، مع أسهم تبين اتجاه الحركة (عرض فقط، بلا أزرار) |
| التصادم المرن لجسيمات الغاز | `gas-elastic-collision/` | نسخة من محاكاة الحركة العشوائية بعنوان وشرح عن التصادم المرن: مجموع الطاقة الحركية للجسيمات يبقى ثابتًا (عرض فقط، بلا أزرار) |
| استحالة إسالة الغاز المثالي | `ideal-gas-liquefaction/` | أسطوانة بمكبس وشريط حرارة: الغاز المثالي يبقى غازًا مهما برد وانضغط (قوى التجاذب معدومة)، والغاز الحقيقي تتقارب جسيماته ويتكاثف سائلًا |
| متوسط الطاقة الحركية ودرجة الحرارة | `gas-kinetic-energy/` | إناء دائري فوق لهب يكبر مع منزلق الحرارة: رفع درجة الحرارة يزيد سرعة الجسيمات بوضوح، فيزداد متوسط الطاقة الحركية |
| الغاز الحقيقي | `real-gas-liquefaction/` | نسخة من محاكاة الإسالة للغاز الحقيقي وحده (بلا زرّي نوع الغاز)، مع زر إيقاف/تشغيل للشرح وشرح ثابت عن انحراف الغاز الحقيقي عن السلوك المثالي (مثال الهيليوم) |


## إضافة محاكاة جديدة

1. أنشئ مجلدًا جديدًا فيه `index.html` مستقل بذاته (بلا اعتماديات خارجية ما أمكن).
2. أضف بطاقة له في `index.html` بالجذر.
3. ادفع إلى `main` — تُنشر Pages تلقائيًا.
